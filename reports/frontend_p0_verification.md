# Phase 4 P0 実装・動作確認レポート

`docs/ui_spec.md` に基づき、React + Vite + TypeScript でP0スコープを実装した。
実際にバックエンド（FastAPI, port 8000）とフロントエンド（Vite dev server）を起動し、
Playwright制御下のヘッドレスChromiumで実際に操作して動作確認した（モックデータは使用していない）。

## 実装したもの

### [B] 入力画面
- タイトル検索（2文字以上・300msデバウンス、`/questions?q=`）
- 並び替えタブ（おすすめ/人気/途中で止まりやすい作品）。`low_completion`タブは専用の説明文付き
- 絞り込み（年代・ジャンル複数選択・話数）。すべてクリアあり
- 進捗表示（UI仕様書3.6の5段階の文言をそのまま実装）
- 3ボタンカード（好き/完走/途中で止まった、排他選択、再タップで解除）
- 無限スクロール（IntersectionObserver）
- フッターCTA（5本以上で表示、`結果を見る（N本）`）

### [C] ブロック2: タイプ診断カード
`/predict` の `profile` をそのまま表示。タイプ名・耐久話数・完走率(平均併記)・好む/避ける傾向。

### [C] ブロック5: 脱落曲線グラフ
`profile.curve` をSVGで描画。個人曲線（太・濃・実線）と全体平均（細・淡・破線）を重ねて表示。
データ不足時は「もう少し回答すると表示されます」を表示しブロック非表示にする代替文言。

### [D] 単体判定の脱落曲線部分
`/predict/single` を呼ぶ最小限の検索フォーム（P1で本実装するブロック1の代わりに、[D]の
動作確認のために用意した簡易版）。話数別バーチャート、ピーク話数のハイライト、
`insufficient_data`（＝`has_meaningful_peak`がfalse）の場合は「この作品には特定の
脱落ポイントが見られません」に切り替え。

| 主表示はrelative_risk、副表示に完走率 | [D]で実装（「平均よりX倍止まりやすい/完走しやすい」＋完走率併記） |
| 回答してもカードが消えない | 実装済み・実機で確認（背景色のみ変化） |
| 「見てない」ボタンを作らない | 未実装（意図通り。未回答＝スキップ） |
| 5本未満で結果を出さない | `/result`直接アクセス時、5本未満なら`/`へリダイレクト（実機で確認） |
| 20本を超えて回答を促さない | 進捗文言が20本で頭打ち（「精度：高。十分です」で固定） |
| MALの画像を直リンクしない | 画像を一切使用していない |
| 回答をlocalStorageに保持 | 実装済み。リロード・画面遷移後も保持されることを実機で確認 |
| is_estimated/is_ongoing/confidenceを必ず表示 | [D]で実装（推定バッジ・信頼度バッジ） |
| at_riskが0件の場合の専用文言 | **未実装**（ブロック3自体がP1スコープのため。P1着手時に対応） |

## 動作確認（実機）

1. **入力画面**: `/questions`から実データ20件を取得しカード表示。検索・並び替え・絞り込みが機能
2. **5本回答→結果画面**: 好き1・完走2・途中で止まった2 を回答。進捗が「5本回答」に更新、
   フッターCTA「結果を見る（5本）」が出現しクリックで`/result`へ遷移
3. **カードの永続性**: 回答後もカードは消えず、再タップで解除できることを確認（進捗5→4に変化）
4. **タイプ診断カード**: 実データで「長距離・熱血・王道派タイプ」等、ネガティブな語を含まない
   タイプ名が表示されることを確認
5. **脱落曲線グラフ**: 個人曲線（太・青）と全体平均（細・破線）が重なって表示されることを確認
6. **単体判定（通常作品）**: 「デスノート」を検索→判定。話数別バーチャート・ピーク話数
   （25話）・信頼度「高」が正しく表示
7. **単体判定（放送中作品）**: 「ONE PIECE」を検索→判定。「推定」プレフィックス、
   信頼度「低」、「放送中の作品のため、完走データが不足しています。内容の傾向から
   推定しています」の注記、「この作品には特定の脱落ポイントが見られません」が
   すべて正しく表示（Phase 3で実装した`is_ongoing`ロジックとの結合を確認）
8. **localStorage永続化**: 結果画面でリロードしても回答・診断結果が保持されることを確認
9. **デスクトップ幅**: 1280px viewportで中央寄せ最大720px・横スクロールなしを確認
10. **コンソールエラー**: 全シナリオを通じてブラウザコンソールエラーは0件

## 技術構成

- `frontend/`: React 19 + Vite + TypeScript, react-router-dom
- `vite.config.ts`: `/api` を `http://127.0.0.1:8000` にプロキシ（CORS設定不要）
- 起動: バックエンド `python3 -m uvicorn api.main:app --port 8000`、
  フロントエンド `cd frontend && npm run dev`
